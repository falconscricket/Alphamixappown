Alpha WA - WhatsApp Web + Alpha (V30) in its own app

BUILD (GitHub, free, no PC needed):
1. github.com -> New repository (private) -> upload all files of this folder (keep .github folder).
2. Actions tab -> "Build APK" -> Run workflow (it also runs on every upload).
3. When green: open the run -> Artifacts -> AlphaWA-apk -> download -> unzip -> app-debug.apk -> install.

FIRST USE: allow Microphone + Camera. Scan the WhatsApp QR (Linked devices). Alpha panel shows
the lock screen with your ID -> send it to the owner, tap "Check again" after approval.
Keep the app open on screen during calls.
